# Reusable App Templates

These are starter templates you can copy for any hackday event. Pick the one that fits your idea best.

## Available Templates

| Template | Best for | Command |
|----------|----------|---------|
| **nextjs** | Web apps, dashboards, interactive tools | `cp -r templates/nextjs events/EVENT/apps/TEAM` |
| **python** | Data analysis, APIs, scrapers, ML | `cp -r templates/python events/EVENT/apps/TEAM` |

## Adding a New Template

If you build something reusable (e.g., a Streamlit template, a Chrome extension starter), add it here for future hackdays.
