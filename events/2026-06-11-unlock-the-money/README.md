# Hackday Q2 2026 — "Unlock the Money"

## Theme

Build tools that make climate finance flow. If funders can't trust cities, money doesn't move. We build the trust layer.

## Schedule

| When | What |
|------|------|
| **11 June 2026, 15:00 GMT** | Kickoff — pitch ideas, form teams, start building |
| **12 June 2026, 15:00 GMT** | Demos — 5 min per team |

## Format

- **Teams of 2-4 people.** Mix technical + non-technical. Everyone codes (with AI help).
- **24 hours to ship.** Something demoable. Ugly is fine. Broken is fine. Invisible is not.
- **Revenue angle required.** Every project answers: *"How does this help OEF or our partners unlock funding, close deals, or generate revenue?"*

## How to Participate

1. Read [GETTING-STARTED.md](../../GETTING-STARTED.md) — especially if you're new to coding
2. Browse [IDEAS.md](./IDEAS.md) — pick one or bring your own
3. Form a team (at kickoff or beforehand in Slack)
4. Copy the template and start building:

```bash
cp -r events/2026-06-11-unlock-the-money/apps/_template events/2026-06-11-unlock-the-money/apps/YOUR-TEAM-NAME
git checkout -b hackday/2026-06-11/YOUR-TEAM-NAME
```

## Tooling

| Use | Don't use |
|-----|-----------|
| Cursor (IDE) | VS Code, Windsurf, other editors |
| Claude (Code, Chat, Design) | GitHub Copilot, ChatGPT for code |
| Any public API or dataset | Private/paid APIs without approval |

## Revenue Angles

| Angle | Example |
|-------|---------|
| **Funder tools** | Help BNDES/CCFLA trust cities enough to deploy capital. OEF = trust infrastructure. |
| **Product features** | Premium CityCatalyst capabilities that cities or consultancies pay for. |
| **Data services** | Scoring, analytics, MRV-as-a-service that partners subscribe to. |
| **Partnership enablers** | Tools that make partnership conversations convert faster. |
